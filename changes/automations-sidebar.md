Added
Automations now appear in a sidebar section below Projects when the host enables them, with each card showing its schedule, target, state, next run, and last result, and opening an automation's thread shows controls to run now, pause or resume, or delete it while keeping the thread.
Cards display the host's target path. Retrying an unconfirmed run uses the same request even after switching machines, reopening Plait, or saving a draft in preview.84 and upgrading again. Cards with unsupported fields stay visible with their controls disabled, alongside the other automations.
Cards recheck the host when a scheduled run is due, so an idle sidebar can show a new pause reason and receipt. A refresh already in progress preserves later successful actions, including deletion.
