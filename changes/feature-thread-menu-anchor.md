Changed
A thread's actions menu now opens beside the thread instead of at the bottom of
the sidebar. Switching from a thread menu or archive confirmation to another
thread’s menu keeps the original focus target for Escape. Right-clicking a thread closes Show All Tabs. Only the open
thread’s menu shows keyboard shortcuts. Cmd-Option-R renames the open
thread and Cmd-Option-A archives or unarchives it. Archiving by shortcut, the
Thread menu, or the palette asks first; tick Remember this setting to stop
asking, or change it under Settings → Keyboard.
