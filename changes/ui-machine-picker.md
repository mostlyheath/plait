The sidebar machine menu shows saved addresses and offers reconnect, host updates, and switch retries. Switch machines by name in the command palette or by number with Ctrl-1 through Ctrl-9. The menu keeps your highlighted machine when connection status changes and closes when focus moves away. Switching machines dismisses the previous machine’s pickers and dialogs.
Retrying an unconfirmed thread creation uses its original machine, checkout identity and request. Retrying the switch to This Mac after a confirmed removal completes that removal.
Choosing This Mac during a startup connection saves that choice. Machine palette hints follow the installed shortcuts, and removing the active remote returns to the saved local machine.
