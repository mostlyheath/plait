Plait

This installer contains the native client and an independent per-user host daemon. The host includes Node and the pinned agent runtime. No Homebrew or global Node installation is needed to run the host.

The host starts for the logged-in user and at later graphical logins. Threads, build caches, and credentials stay in your home directory, outside the installed programs.

Use Customize to select components. Client-only and host-only packages are also available for independent updates.

Plait is ad-hoc signed and not notarized. Only install an artifact whose source and origin you trust. Do not disable Gatekeeper.
