Next steps

Open Plait from Applications. Open your repository, then use Settings to check the local host and select an authenticated model. The host uses your existing Pi authentication. Model requests require network access.

Approve only the exact edits and commands you intend. Closing the client does not stop the host. Commands can read checkout files, including ignored files, and send their contents to the model provider.

Updates

A client update does not stop the host. A host update installs a new immutable runtime without stopping active work. Finish or Stop your threads before logging out and back in to activate a host update. An existing manually started host is never killed by this installer.

Keep your development toolchains installed. The package includes the agent runtime, not Rust, Xcode, or project dependencies. To work on another machine, add it in Settings → Machines; see the guide for remote hosts. Sandboxed commands are available on macOS only.
